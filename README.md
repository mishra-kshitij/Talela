## ✨ About the Project

This repository contains the front-end source code for the Talela brand website.

The website is designed to establish Talela's digital identity, showcase its food offerings, communicate its brand philosophy and build anticipation for its upcoming launch across Central India.

The design takes inspiration from Talela's signature yellow, orange and black branding, with bold typography, playful visual elements and food-focused layouts.

## 🎨 Design & Features

- **Vibrant Brand Identity:** A distinctive yellow, orange and black colour palette inspired by the Talela logo.
- **Responsive Design:** Optimised layouts for desktop, tablet and mobile devices.
- **Animated Hero Section:** Floating food imagery, decorative elements and subtle motion effects.
- **Interactive Navigation:** Responsive mobile navigation with smooth section navigation.
- **Food Showcase:** Dedicated sections for Pakoda Party, Bhajia Bliss and Chai Scene.
- **Brand Story:** An introduction to Talela's philosophy and food culture.
- **Animated Scrolling Ticker:** Showcasing the brand's signature food and personality.
- **Scroll Animations:** Subtle reveal effects as visitors explore the website.
- **Accessibility:** Keyboard navigation, focus indicators and reduced-motion support.
- **SEO & Social Sharing:** Meta descriptions, Open Graph metadata and social preview support.

## 🛠️ Technology Stack

| Technology | Purpose |

## 🚀 Getting Started

You can run the website locally without installing any additional frameworks or dependencies.

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/tatela-website.git
```

**2. Navigate to the project directory**

```bash
cd tatela-website
```

**3. Launch the website**

Open `index.html` directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for local development.

## 🌐 Deployment

The website can be hosted using GitHub Pages or any static website hosting provider.

**GitHub Pages deployment:**

1. Push the website source files to your GitHub repository.
2. Navigate to repository Settings.
3. Open Pages under the Code and automation section.
4. Select Deploy from a branch.
5. Choose the `main` branch and `/ (root)` directory.
6. Save your configuration.

For the custom domain:

- Configure `tatela.in` in the GitHub Pages custom domain settings.
- Add the DNS records recommended by GitHub.
- Enable HTTPS once domain verification is complete.

Refer to the [GitHub Pages documentation](https://docs.github.com/en/pages) for deployment instructions.

## ⚡ Performance & Optimisation

The website incorporates several front-end optimisation practices:

- Lazy loading for below-the-fold images.
- Prioritised loading of the main hero image.
- Asynchronous image decoding.
- Lightweight CSS and vanilla JavaScript.
- Responsive image presentation.
- Reduced-motion accessibility support.
- Optimised brand logo and favicon assets.
